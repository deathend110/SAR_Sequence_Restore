# SAR 双卡短程验证报告（2026-10-28）

本报告保留 2026-10-28 的 SwinIR/HINT 实验设置和测量结果。包含后续 UCAN 接入在内的当前正式参数见 [README_SAR.md](README_SAR.md#数据和训练协议)；本报告中的短训步数和微调学习率用于当次实验。

## 结论与建议

现有 HINT 权重可作为 Q=2 的快速恢复起点。本轮微调没有带来明确的整体收益；FP32 下增大 batch 的测试均触及显存上限。建议保留 SwinIR 每卡 3、HINT 每卡 6，以及此前缩短的正式训练预算。

## 执行范围

- 使用 GPU 0、1，两张 RTX 4090；PyTorch 2.6.0+cu124、BasicSR 1.4.2。
- 作业时段：15:49:38～16:28:15（Asia/Shanghai），约 38.6 分钟。
- 共 19 个独立作业，其中 4 个为触及容量边界的 OOM 测试；其他作业正常完成。单个训练作业最多 400 步。
- 不启用 AMP；基线、微调和 batch 测速沿用默认后端设置（matmul TF32=false、cuDNN TF32=true）。
- 生产训练代码、正式 YML、历史权重均未改动；新增文件仅为实验脚本、TODO 和报告。
- 验证/测试各选七类场景各一条序列、全部 F0～F8，共各 63 帧；训练仍使用完整 train 划分。
- 指标沿用 uint8 image-based PSNR/SSIM、crop_border=0、非 Y 通道；评估完整 512×512，训练随机裁剪 128×128。
- HINT 评估使用固定双卡分片和冷缓存，评估后恢复训练缓存，保证中途评估不改变训练轨迹。

## 1. 已有权重直接评估 Q=2

| 模型 | 历史权重迭代 | 验证 PSNR / SSIM | 测试 PSNR / SSIM |

| SWINIR | 493358 | 25.1673 / 0.8035 | 23.0577 / 0.7800 |
| HINT | 813496 | 25.5124 / 0.8101 | 23.9897 / 0.8000 |

测试子集输入为 21.1098 dB / 0.7504。这里比较的是各自已有权重的可用性，两份历史权重的训练曝光量不同。

## 2. 短程微调与阶段检查

加载历史最优 PSNR `.pth`，新建 Adam，学习率 5e-5，在预算 75% 处减半；不加载旧 `.state`。SwinIR 400 步、HINT 200 步，各处理 2400 个训练样本。每 1/4 预算验证一次，以验证 PSNR 选权重，step0 也参与选择；选定后评估测试子集。

| 模型 | 验证选中步数 | 测试 PSNR / SSIM | 相对原权重 ΔPSNR / ΔSSIM |
|---|---:|---:|---:|
| SWINIR | 200 | 23.0799 / 0.7837 | +0.0222 / +0.0037 |
| HINT | 50 | 23.9883 / 0.7985 | -0.0014 / -0.0015 |

SwinIR 的 PSNR 增益很小，七个场景中四个上升、三个下降；HINT 测试 PSNR 基本持平、SSIM 略降。本轮结果支持先使用已有权重，不支持直接投入长时间微调。

## 3. Batch 容量与吞吐量

各档独立启动双卡 DDP，计划运行 50 步，排除前 10 步；稳态计时包含取数据、前后向、优化器和同步。峰值为两卡中较大的 PyTorch allocated 显存，和 nvidia-smi 进程占用口径不同。

| 模型 | 每卡 batch | 状态 | 样本/秒（双卡） | 峰值 allocated GiB/卡 |
|---|---:|---|---:|---:|
| SWINIR | 3 | 完成 | 16.62 | 19.36 |
| SWINIR | 4 | CUDA OOM | — | — |
| SWINIR | 6 | CUDA OOM | — | — |
| HINT | 6 | 完成 | 26.39 | 20.98 |
| HINT | 8 | CUDA OOM | — | — |
| HINT | 10 | CUDA OOM | — | — |

维持当前 batch。训练取数据平均耗时约 0.002～0.003 秒，显著小于计算时间，暂不优先增加 worker 或改造数据存储。

## 4. HINT warmup 启动对照

先固定种子执行探索对照，复核发现默认后端下首步 loss 不一致。单步审计确认权重及两卡首批输入 SHA256 一致；固定后端后两组首步 loss 均为 0.3648087978。

因此以下使用重新运行的受控对照：禁用 cuDNN benchmark、关闭 TF32、启用 cuDNN deterministic 和确定性算法请求，并设置 CUBLAS_WORKSPACE_CONFIG=:4096:8。两组仍各 400 步，初始权重和首批输入摘要相同，种子及训练数据顺序固定。

| 步数 | 无 warmup PSNR / SSIM | 3000 步 warmup PSNR / SSIM |
|---:|---:|---:|
| 100 | 20.8865 / 0.6377 | 18.8203 / 0.5832 |
| 200 | 21.4955 / 0.6802 | 19.5315 / 0.6028 |
| 300 | 21.5757 / 0.6811 | 20.7956 / 0.6355 |
| 400 | 21.9238 / 0.6920 | 20.8314 / 0.6379 |

末 100 步平均 Charbonnier loss：无 warmup 0.063359，3000 步 warmup 0.070859。两组均完成且 loss 有限。

第 400 步 warmup 学习率为 4.6186667e-05，无 warmup 为 0.0003464。该对照观察到 3000 步预热的起步更慢，当前正式配置保留 warmup_iter=-1。其最终收敛效果由完整预热后的实验评价。

固定后端是对照质量控制措施，不作为提速方案；此处的运行速度不与默认后端的 batch 测速直接混合比较。

## 5. 重复性与结果适用范围

HINT 原权重测试 PSNR 两次为 23.989724 和 23.989667，变化约 0.000057 dB。

本轮以场景均衡的 63 帧子集和有限训练预算筛选方案。微调是否推广，应结合完整验证集及各场景收益继续判断。原、新数据集的 fr、fa 等参数也不同，已有权重直接评估反映整套数据设置间的迁移表现。HINT 的本次缓存隔离协议与正式训练验证后继续保留缓存的行为有区别。

## 6. 推荐落地设置与文件

- 保留已更新的正式预算：SwinIR 80 万步、HINT 40 万步及对应提前衰减节点。
- 保留每卡 batch：SwinIR 3、HINT 6；当前 FP32 模型不直接增大 batch。
- Q=2 快速恢复优先试已有 HINT 权重；SwinIR 短程微调权重保留为候选，HINT 优先保留原权重。
- HINT 当前保留无 warmup；涉及小幅数值差异的启动实验先固定后端并核查首步。
- 阶段选择优先验证集最优权重，避免仅使用最后一组。
