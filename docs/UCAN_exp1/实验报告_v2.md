# 单比特 SAR 跨帧 Token 交互实验报告 v2

> **实验依据**：[后续实验推进计划_v2.md](后续实验推进计划_v2.md)（基于 [实验报告.md](实验报告.md) v1 与 [SAR Dataset Transformer](../../SAR%20Dataset%20Transformer/) 源码核查制定）  
> **硬件调度原则**：每次任务启动前实时检测 `nvidia-smi` 空闲 GPU，不写死卡号、不与外部高负载进程抢卡。  
> **数据口径**：主研发锁定 `qh2p5_ql1p5` + `scene_split_v1`（`train`: 3,344 seq / `val`: `sar_figure` 270 seq / `test`: `city1_histeq` 484 seq）；定型后再在现成 `qh4_ql2` 上验证大 $\Delta Q$ 泛化。  
> **核心优先级**：以 **大幅拉升 `F4` / `F4 中心`、拉平 V 谷（缩小 $\overline{F_{0,8}}-F_4$）** 为第一目标，参数量预算放宽至 `2–3 M`。

## 1. v2 起点复盘与 v1 基线对照

v1 阶段虽验证了 `C_s42 − B_s42 = +0.1100 dB`（Test），但放回公共单帧底座 `A_init`（`60k`）对比时，`C_s42` 存在三大问题：
1. **序列微调破坏底座**：`A_init → A_s42`（`64×512`, `global_batch=2`, `lr=1e-4` 全参续训）导致 Test 九帧降 `−0.0955 dB`、F4 降 `−0.1552 dB`、`peak_err` 从 `25.34` 恶化到 `31.42`；
2. **V 谷反而加深、SSIM 未涨**：Test `C_s42` 相对 `A_init` 九帧 PSNR 仅高 `+0.0283 dB`（与零训练 `A_init+Fusion` 持平），但 F4 低 `−0.0110 dB`、F4 中心低 `−0.0311 dB`、SSIM 低 `−0.0026`、V 谷深反而从 `0.5933 dB` 增至 `0.6794 dB`、`peak_err` 恶化至 `30.84`；
3. **有效信号特征明确**：`SAR Dataset Transformer` 源码核查与实测表明，邻帧 384px 重叠区 LQ 几乎恒等（MAD `~0.00007`），而剔除全局仿射偏移后的真实结构 H−L 落差在 `city1_histeq` 上达 **`+1.17 dB`**（`24.77` vs `23.60`）。

## 2. Step 1：零训练 `512×1536` 整画布摸底诊断（`diagnose_canvas_1536.py`）

- **执行条件**：冻结 `A_init`（[net_g_best_psnr.pth](../../experiments/ucan_a_init_scene_v1/models/net_g_best_psnr.pth)，`683,817` 参数），双卡 `CUDA_VISIBLE_DEVICES=2,3`。
- **显存探针结果**：全高 `[1, 1, 512, 1536]` 单次前向超出 24 GiB 单卡显存（`oom_fallback=True`），自动安全回退至 `slice_height=256, slice_stride=128`（实测峰值 Allocated `10.83 GiB`，Reserved `14.64 GiB`）；并在完全相同切片参数 `slice 256/128` 下运行 `frame512` 公平对照（峰值 Allocated `3.65 GiB`，Reserved `4.92 GiB`）。
- **结果目录**：[canvas_1536_upperbound](diagnostics/canvas_1536_upperbound/)

### 2.3 Step 1 机理判定与对 Step 3 的分支结论
1. **消除窗边界截断真实有效但仅惠及 H 边界与去冗余提速**：在 `city1_histeq` 上，`canvas1536` 显著提升了 `H 边界`（`+0.0862 dB` vs `raw`，`+0.0400 dB` vs `+Fusion`）、将非目标亮点 `false_bright` 降低 `19.5%`、重叠 MAD 归零且网络耗时降为逐帧推理的 **`37.6%`**。
2. **仅靠扩大感受野至 1536px 无法显著提升 F4 与拉平 V 谷**：`canvas1536` 在 `F4` 上相比 `frame512+Fusion` 在 Test 仅差 `+0.0023 dB`（`F4 中心` `-0.0008 dB`，V 谷反而加深 `+0.0427 dB`），在强辐射偏移验证集 `sar_figure` 上因整画布全局线性注意力混合不同区域辐射统计及未训练 `W=1536` 的 `1D-FOPE` 行距，反而下降 `-0.0524 dB`。
3. **Step 3 分支门控明确**：依据计划门控条件，**Step 3 主线倾向采用分支 `3-R`（`RG2` 尺度不变标定 + `RG3` 显式 `H→L` 非局部高频检索 + 输出端质量非对称门控 + 必要时结合去冗余地面编码）**，而不再指望仅靠打通 `1536px` 感受野自动提升 `F4`。
