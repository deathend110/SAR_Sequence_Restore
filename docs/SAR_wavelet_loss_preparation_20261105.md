# SAR 小波损失：UCAN 源码核对与预备实现

日期：2026-11-05。

本次增加可由 `build_loss` 创建的 `SWTLoss`，用于后续损失消融准备。当前训练仍使用 Charbonnier；未修改训练 YAML、`SRModel` 或训练进程。以下 SAR 适用性分析属于基于损失结构的理论判断，尚非本数据集的精度实验结果。

## UCAN 官方代码实际怎样使用

核对版本：`hokiyoshi/UCAN@b812c0adb8ce70d442973db5c87bab7d1e8c3333`。

- [losses.py / SWTLoss](https://github.com/hokiyoshi/UCAN/blob/b812c0adb8ce70d442973db5c87bab7d1e8c3333/basicsr/losses/losses.py)：损失定义。
- [SWT.py](https://github.com/hokiyoshi/UCAN/blob/b812c0adb8ce70d442973db5c87bab7d1e8c3333/basicsr/losses/SWT.py)：不降采样的可分离分析滤波。
- [sr_model.py](https://github.com/hokiyoshi/UCAN/blob/b812c0adb8ce70d442973db5c87bab7d1e8c3333/basicsr/models/sr_model.py)：通过 `train.swt_opt` 创建损失，将 `l_swt` 加入 `l_total` 后共同反向传播。
- [论文第 4.2 节](https://arxiv.org/html/2603.11680v1#S4.SS2)：训练包含 L1、LDL 与 Wavelet 三项。

官方 `SWTLoss` 的计算顺序：

1. 预测图与 GT 都由 RGB 转为 `Y = 16 + 65.481R + 128.553G + 24.966B`。当 RGB 在 `[0,1]` 时，Y 约在 `[16,235]`。
2. 使用 `sym19` 小波，分析滤波器长度为 38。低通除以其系数和，使直流增益为 1；高通保留原始系数。这个归一化不等同于 PyWavelets 的 `norm=True`。
3. 使用单层 SWT、周期延拓，得到同尺寸 LL、LH、HL、HH 四个子带。这里没有小波阈值去噪，也没有多层尺度金字塔。
4. 各子带分别计算预测与 GT 的 L1，再按子带权重相加。类默认四项权重均为 `0.01`，默认 `reduction='mean'`。因此它同时约束低频与高频，并非只强调高频。

该版本只提供 Test YAML，未提供 README 中引用的 Train YAML。因此 `0.01` 是可确认的类默认值，不能据此确定论文各次训练实际使用的配置权重。原实现每次前向都重新创建滤波器并调用 `.to('cuda')`，没有灰度输入与 CPU 适配。

## 小波损失针对的误差

对固定线性小波分析算子 $W_b$，损失为：

$$
L_{\mathrm{SWT}}=\lambda\sum_{b\in\{LL,LH,HL,HH\}}w_b\,\mathrm{mean}\left|W_b(\hat I)-W_b(I_{\mathrm{GT}})\right|
=\lambda\sum_b w_b\,\mathrm{mean}\left|W_b(\hat I-I_{\mathrm{GT}})\right|.
$$

它对残差进行有方向的邻域滤波，改变不同空间结构误差的代价。普通像素 L1 直接累计各位置的误差绝对值，小波 L1 进一步区分误差如何在邻域中排列。它没有增加输入的观测信息，也不是从小波变换本身推导出了更高 PSNR 的保证。

以 Haar 为例，高通子带近似局部差分，可以显式约束局部对比度、边缘和方向结构。`sym19` 使用更长的滤波器，在更大的局部范围内进行频率分离。对比之下，如果只是完整正交变换后计算无加权平方误差，Parseval 等式可能使其与原空间平方误差等价；不能把这种情况当作小波损失必然提供独立信息的依据。本实现采用 SWT 和子带 L1，损失几何与该情况不同。

SWT 不进行下采样，具有平移等变性；在周期边界下，对预测与 GT 共同作相同循环平移，损失不变。它减少了下采样引起的采样相位依赖，但仍要求预测与 GT 对齐，不能用来容忍两者的相对错位。相关性质见 [PyWavelets SWT 官方文档](https://pywavelets.readthedocs.io/en/latest/ref/swt-stationary-wavelet-transform.html)。

## 对单比特 SAR 恢复的优势与适用范围

| 误差或场景 | 理论上能够补充的约束 | 适用范围与代价 |
|---|---|---|
| 边缘变钝、细线断裂、局部对比度不足 | 方向高通子带能约束这些结构与 GT 的差别 | 更适合输入仍有可恢复结构且 GT 对齐的情况；权重过大可能牺牲整体像素精度 |
| 散射点形状变宽或周围出现条纹 | 点响应与条纹在不同子带形成系数误差 | 小波不是 SAR 点扩散函数；不能保证分别改善主瓣、旁瓣和散射幅度 |
| 距离向与方位向退化程度不同 | LH 与 HL 可独立设置权重，保留数组方向 | 先核对 H/W 与距离向/方位向的映射；方向权重不会自动知道物理轴含义 |
| 低频幅度分布或区域对比度偏差 | LL 子带补充区域性误差约束 | 仍应保留基础重建损失；不宜只用高频项导致亮度/幅度约束不足 |
| GT 中保留相干斑与细小散射结构 | 直接匹配 GT 的高频系数，而不是无条件抹平 | 无法自动区分细节、相干斑和噪声；GT 的定义决定了模型被要求保留什么 |

主要不利区间与限制：

- **严重量化信息丢失、弱目标接近不可辨识时**：损失不能补回不存在的观测信息。过强的细节约束可能推动模型学习训练集先验，必须同时检查虚假亮点与弱目标保留。现阶段不能给出某个 Q 值以下必然有害的阈值。
- **GT 与输入配准存在误差时**：边缘错位会造成高频系数差异；SWT 的平移性质并不消除配对错位误差。
- **高频包含明显干扰、GT 自身含噪或存在压缩/裁剪失真时**：小波损失也会拟合这些目标系数。我们的目标是逼近全精度 RD 成像 GT，不应把所有高频或相干斑当作需要删除的噪声。
- **子带权重过大时**：可能改善某些结构却降低全图 PSNR、改变散射幅度或使局部对比度过强。需要联合比较结构与像素误差，不能只看结果是否更锐。
- **小 patch 配合长滤波器时**：`sym19` 需要每侧约 18/19 像素延拓；128×128 crop 中约 49.5% 的系数位置涉及至少一个方向的边界延拓。这是支撑域覆盖比例，不代表这些位置都产生明显误差。周期延拓将两侧相接；反射延拓也只是边界近似，可与短滤波器或只评价内部区域的策略比较。
- **计算预算紧张时**：SWT 保留四组同尺寸系数，会增加训练计算和中间张量；损失不进入网络推理，因此不增加推理参数与推理 FLOPs。

它能够惩罚鬼目标造成的系数误差，但没有编码单比特量化、谐波阶次或 SAR 成像算子，不能将其称为专门的单比特谐波抑制损失。

## 本地实现与上游差异

新增 `basicsr/losses/wavelet_loss.py`，由现有 `_loss.py` 扫描逻辑自动注册为 `SWTLoss`。

| 项目 | 本地实现 |
|---|---|
| 小波与层数 | 默认单层 `sym19`，另支持 `haar` 作为短滤波器对照 |
| 输入 | `[N,C,H,W]`，逐通道处理；SAR 直接使用 `[0,1]` 单通道，不进行 RGB→Y 转换 |
| 边界 | 默认 `reflect`，可选择与 UCAN 一致的 `periodic`；`sym19 + reflect` 要求 H、W 均大于 19 |
| 子带顺序 | 按 UCAN 的宽度先滤波顺序：LL、LH、HL、HH；LH 为宽度低通/高度高通，HL 为宽度高通/高度低通 |
| 权重 | 保留四个子带的 `0.01` 默认值，另提供整体 `loss_weight`；不是已验证的 SAR 最优权重 |
| 数值尺度 | 灰度值直接使用单位范围；若把同一灰度图复制为 RGB，UCAN 的 Y 差值会额外放大 219 倍，因此不能照搬数值权重来宣称等效训练强度 |
| 实现 | 固定滤波器注册为 buffer，不需要 PyWavelets 或硬编码 CUDA；使用分组可分离卷积，支持 CPU、不同设备与奇数尺寸 |
| 计算 | 利用线性关系只变换 `pred-target`；避免分别变换两图的重复计算。浮点舍入顺序与上游不同，不能要求逐 bit 一致 |
| 启用状态 | 只有损失类；未在 `SRModel` 增加 `swt_opt` 分支，未在任何正式 YAML 中配置该项 |

下列片段仅说明如何单独创建损失，**不是当前训练配置**：

```python
from basicsr.losses import build_loss

criterion = build_loss({
    'type': 'SWTLoss',
    'wavelet': 'sym19',
    'mode': 'reflect',
    'loss_weight': 1.0,
    'loss_weight_ll': 0.01,
    'loss_weight_lh': 0.01,
    'loss_weight_hl': 0.01,
    'loss_weight_hh': 0.01,
})
```

以后若启用，应增加明确的辅助损失训练分支与独立日志项，保持 Charbonnier 为基础项，分别比较小波类型、边界和权重。评估除 PSNR/SSIM 外，还应固定显示范围检查强弱散射点、细线与虚假目标。不能仅在现有 YAML 增加一个当前训练器尚未读取的 `swt_opt` 字段。

## 验证

CPU 测试覆盖：Haar 手算方向与归一化、灰度/多通道独立性、同图零损失、常量误差低频响应、三种 reduction、循环平移等变性、数值梯度与异常输入。

```bash
OMP_NUM_THREADS=2 MKL_NUM_THREADS=2 .venv/bin/python -m pytest -o addopts='' \
  tests/test_losses/test_wavelet_loss.py tests/test_losses/test_losses.py -q
```

另用隔离目录中的 PyWavelets 1.8.0 对照滤波器及 `swt2` 数值；该依赖只用于参考验证，不安装到训练环境。并将 UCAN 固定版本的 `SWTForward` 放在临时目录，在相同边界和灰度尺度下对照前向与梯度。

参考对照覆盖 128×128 灰度 patch、39×41 三通道奇数尺寸和反射边界，分别检查 FP32 与 FP64。六组变换系数与上游完全一致；损失值通过浮点容差检查，FP64 梯度一致。FP32 的 128×128 样本中，由于 `W(pred-target)` 与 `W(pred)-W(target)` 的舍入顺序不同，极小系数附近的 L1 子梯度有差异，最大梯度差约 `2.23e-7`、梯度整体相对 L2 差约 `0.30%`；其余两组 FP32 梯度一致。这属于等价计算路径的有限精度差异，不将其描述为逐 bit 复现。

本次启用隔离参考包后的验证结果：**22 项通过**，包括 16 项小波损失检查、4 项原有基础损失检查、2 项现有 UCAN 配置协议检查。未执行训练或 GPU 性能测试；新增损失对 PSNR/SSIM 的实际收益留待后续消融。
